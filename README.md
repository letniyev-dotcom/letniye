# letniye (Android, Jetpack Compose)

Лента-демо, перенесённая из `letniye_41.html`. Профиль пока не переписан.

Карточки: заметки — стекло цвета заметки (`Post.col`), музыка — обложка на всю карточку с прогрессивным блюром (блюр с Android 12), даты под карточками (`SHOW_DATES`).

## Сборка
Только release. GitHub Actions (`.github/workflows/release.yml`) запускается на push в `main`, на теги `v*` и вручную.
APK лежит в Artifacts запуска (`letniye-release-apk`), для тегов — ещё и в GitHub Releases.

## Подпись
Без настройки APK подписывается одноразовым ключом (ставится, но обновить поверх сборки с другим ключом нельзя).
Для постоянного ключа добавьте в Settings → Secrets → Actions:
`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` (необязательно).

    keytool -genkeypair -keystore letniye.jks -alias letniye -keyalg RSA -keysize 2048 -validity 10000
    base64 -w0 letniye.jks   # → KEYSTORE_BASE64

## Тема
Светлая по умолчанию. Тёмная — долгое нажатие на логотип в шапке.

## Поле ввода и голосовые
`Island.kt` — одна цельная пилюля (+, поле, кнопка справа), иконки без подложек. Голосовые: удержание кнопки справа,
свайп влево — отмена, вверх — замок → пауза → превью с обрезкой (`Voice.kt`). Готовая запись приходит в `Island(onVoice = …)`,
файл лежит в `filesDir/voice/*.m4a`. Нужно разрешение RECORD_AUDIO (запрашивается при первом удержании).

## Кружки (видео)
Кнопка справа: тап переключает гс ↔ кружок (иконка меняется на «запись кружка»). В режиме кружка удержание кнопки открывает свою камеру
(`Video.kt`, CameraX): чёрный экран, обычное видео на весь кадр, запись до 60 с (тап — старт/стоп), переворот камеры, вспышка.
После записи видео встаёт целиком, поверх — круглая рамка: двигать одним пальцем, масштабировать двумя; всё вне рамки затемнено.
«Отправить» кладёт кружок первым в ленту: mp4 лежит в `filesDir/video/`, в посте хранится положение рамки (`Post.cx/cy/cd` — доли кадра),
в ленте тот же кадр сдвигается и увеличивается под рамку (без перекодирования). Кружок играет без звука, тап включает звук.
Нужны разрешения CAMERA и RECORD_AUDIO (запрашиваются при открытии камеры). Лента пока не сохраняется между запусками.
